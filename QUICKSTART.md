# Quick Start — Pétanque Kassenbuch Master Pro

In 5 Minuten einsatzbereit. Für die ausführliche Anleitung siehe das [Benutzerhandbuch](./BENUTZERHANDBUCH.md).

## 1. Öffnen

Doppelklick auf `kassenbuch_master_pro.html` — öffnet sich im Standardbrowser. Keine Installation nötig.

## 2. Vereinsdaten eintragen (einmalig)

Im Bereich **„⚙️ Vereinsdaten"** eintragen:
- Vereinsname
- Anschrift
- Zuständiges Finanzamt
- Freistellungsbescheid-Datum

→ **„Vereinsdaten speichern"** klicken. (Nur für Spendenquittungen nötig — bei Bedarf später nachholen.)

## 3. Erste Buchung erfassen

1. Zahlungsweg wählen (Barkasse oder Bankkonto)
2. Kategorie wählen
3. Verwendungszweck + Betrag eintragen
4. **„Speichern"**

→ Oder einen der vier **Schnellwahl-Buttons** oben im Formular nutzen, um gängige Buchungen vorzubefüllen.

## 4. Die wichtigsten Buttons auf einen Blick

| Button | Wofür |
|---|---|
| 🖨️ Kassenbericht & Jahresabschluss drucken | Druckfertige Bilanz mit Unterschriftenfeldern |
| 🔒 Buchungen festschreiben (GoBD) | Bisherige Buchungen unveränderlich machen |
| 💾 Als CSV sichern | Export für Excel |
| 📂 Backup einspielen | Zuvor exportierte JSON-Datei zurückladen |
| 🏦 Bankauszug importieren (CSV) | Kontoauszug einlesen statt einzeln eintippen |

## 5. Nicht vergessen

- ⚠️ Alle Daten liegen **nur lokal im Browser dieses Geräts** — kein Cloud-Abgleich.
- 💾 Regelmäßig sichern (CSV-Export oder Backup-Datei aufbewahren).
- 🔒 Vor dem **Festschreiben** immer ein Backup erstellen — der Schritt ist nicht rückgängig zu machen.
